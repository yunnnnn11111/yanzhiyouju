# 言之有据 · 县域农产品可信传播工作台

版本：2026-11-05-catalog-r7。服务于农产品商家和合作社，以烟台苹果为演示场景。六个页面：工作台、批次任务、分析报告、合规规则库、案例库、管理中心。

## 功能与边界

- 游客直接建档与生成，结果临时保存两小时；注册用户按账号隔离；管理员可只读查看全部账号批次、来源、核验与审计记录。
- 联网模式无需模型 API。批次任务中的“联网采集”先查本地案例库，再尝试公开搜索；也可以“提取网页”收集公开材料。人工核验后由规则和模板生成内容。首次直接分析只使用当前已录入档案，不代表已完成实时市场调查。
- Agent 模式调用兼容 Chat Completions 的 API。管理员开关平台 API，用户也可使用自己的服务。未配置或调用失败明确报错；不可绕过本地证据和风险门禁。
- 每批计算七种渠道，推荐一个优先方案、两个备选方案，提供三类文案、人工改稿、风险重审、Markdown/JSON 导出和销售反馈。
- 渠道系数、价格折扣、损耗和物流成本是明确标注的演示模型假设，非实时交易数据。推荐是这些假设下的综合排序，不是“全市场利润最高”保证。当前没有真实买家撮合、自动下单或自动发布功能。
- 照片用于批次展示，不冒充已实现通用视觉识别、OCR 或语音识别。
- 用户有权在网页查看草稿，系统阻断高风险内容的导出和快捷复制，但无法阻止人工抄写页面。规则检查不是法律结论。

## 联网模式与案例库

- 检索顺序：本地案例库 → 公开搜索引擎。案例库命中会以“案例库缓存”标记进入公开来源；实时抓取成功的页面写回检索库，供后续批次复用。
- 案例库只保存公开网页正文、标题、抓取时间和来源级别，不保存用户材料、账号密钥或登录态；命中仍是待核验线索，必须人工确认主体、批次、时效和原件。
- 种子数据位于 data/retrieval_seed.json，由 tools/collect_seed.py 采集、tools/curate_seed.py 清洗后随包分发，当前覆盖烟台苹果、洛川苹果、赣南脐橙、五常大米。运行时数据库为 APP_DATA_DIR/retrieval.db。
- Render 免费实例的本地磁盘不是持久化存储：重启或重新部署后只保留随包种子，实时缓存会丢失。长期运营需要持久磁盘或外部数据库及备份。
- 案例库不改变事实门禁，也不调用模型 API；打开来源后仍需按原流程选择证据类型并核验。

## 合规规则库与案例库页面

- 合规规则库页面展示随包分发的规则库版本（当前 2026.11：10 条规则、8 部全国性法规与标准），每条列出法规依据、触发表述、语境提示和整改建议；来源芯片可直接打开原文出处。规则只做合规筛查提示，不构成法律意见，发布前仍须责任人复核。
- 案例库页面展示 13 篇已采集的公开网页快照与 3 组典型场景用例，标注来源主机、抓取时间和正文 SHA-256 前缀；只展示可读摘要，不返回全文。命中只作线索，引用前请复核原文。
- 两页均为只读展示，数据随 app-source.zip 分发，不接受运行时写入：规则来自 data/rules/compliance_rules.json，网页快照来自 data/retrieval_seed.json，场景用例来自 data/cases.json。
- 公开只读接口：GET /api/rules、GET /api/cases；只返回规则条目与摘要，不含账号、批次或密钥信息，也不改变任何拦截逻辑。

## 三分钟演示

1. 打开工作台，点击“填入烟台苹果示例”，选择联网模式，生成方案。示例数据全部为演示输入，不是真实销售记录。
2. 查看七渠道明细与一主两备方案；打开事实门禁，看到没有证据支撑的产地、等级与名称主张被拦截。
3. 到批次任务，采集公开资料或手工补证。检查发布/抓取时间、有效期、正文快照、SHA-256 和核验人。公开标准只说明规则，不证明本批产品已经认证。
4. 修改传播文案：加入疾病治疗或绝对化承诺，保存重审，验证导出被阻止。整改并重审通过后可导出。
5. 打开合规规则库，核对每条规则引用的法规条款与触发表述；打开案例库，查看已采集快照与典型场景用例的预期结果。
6. 登录管理员查看其他用户批次、证据与审计。管理员不能代替批次所有者修改材料。

## 本地启动与回归

Python 3.12；本地开发运行 python cloud_app.py 后打开 http://127.0.0.1:8000。
可用 PORT 指定端口，APP_DATA_DIR 指定数据目录。

本地开发管理员默认 admin / Yanzhi@2026，首次登录必须改密。公网生产模式不启用该默认密码。
回归命令：python tests/run_checks.py。自动创建隔离临时目录和本地服务，结束后清理；不需要 API 密钥，不调用模型供应商。
语法检查：python -m compileall -q core cloud_app.py，以及 node --check web/app.js。
前端导航回归：node tests/frontend_checks.js。

## 部署与管理员初始化

仓库沿用 app-source.zip 方式：Render 先解压，再安装 requirements.txt。保留已有提交历史。归档仅包含应用源码、内置示例、规则、测试和说明。
必须保持单 worker；文件存储使用进程内锁，当前不支持多进程或多实例共享写入。
生产环境设置 SESSION_SECRET（至少24字符），APP_ENV=production。
平台管理员首次启用需由服务所有者在 Render Environment 配置 ADMIN_USERNAME 与强密码 ADMIN_PASSWORD，保存并部署。生产环境缺少 ADMIN_PASSWORD 时只启用商家/游客功能，不创建弱口令管理员。用户名 admin 及配置的管理员用户名禁止自助注册。
重置账号密码后旧会话失效；重置的用户须再次改密。环境变量密码仅用于首次创建，不会覆盖已存在账号密码。
现有服务若仍使用60秒超时，可在设置中将启动命令的 --timeout 改为120；不影响普通联网模板分析。两三次模型请求可能超过免费实例请求时限，失败时应重试而非冒充成功。

Render 免费实例的本地磁盘不是持久化存储。账号、批次、密钥配置可能随重启/重新部署丢失；正式长期运营需要持久磁盘或数据库及备份。未在此版本自动购买付费资源。

## API 和数据安全

在账户 API 设置填入供应商给出的 HTTPS Base URL、模型名和密钥；界面默认值仅作可编辑初值，须以供应商实际可用模型为准。兼容服务由用户自行配置，不对简称“dsh”猜测提供商。
密钥只发送到所配置服务并加密保存，网页显示掩码；更换服务地址必须重新输入对应密钥。保存配置不产生模型调用；连接测试和 Agent 分析可能产生供应商费用。
模型会收到本批档案、材料摘要与待审文案。网页和上传材料是待分析数据，不具有指令权限。公开抓取拒绝内网与本机地址，不携带用户 API 密钥，不绕过验证码或登录限制。
证据核验是操作者的确认并留痕，不代表平台已经向发证机关验真。相同类型冲突、过期或不匹配材料不能支撑事实。修改档案会要求重新匹配证据，旧报告不能直接导出。
审计哈希链可检测现有记录中未重算的篡改和断链，不能替代第三方存证，也不能证明哈希对应内容本身真实。

## AI 使用与验证披露

本项目在代码、界面与测试完善中使用了 AI 编程辅助；业务 Agent 为可选模型能力，联网模式由本地规则/模板执行。
烟台苹果示例、渠道系数、自动化测试材料均明确为模拟数据。测试不会将模拟证书标记成真实公开认证。
本地验收覆盖账号隔离、管理员只读、过期/冲突证据、风险拦截、报告导出、模式与档案失效、反馈及审计。真实联网采集和实际模型效果需在部署环境结合有效来源、有效供应商配置验证。
目前未声称有真实小范围商家测试、真实成交业绩或收益提升数据。评审前应补充授权的真实批次材料、执行记录及用户反馈。
