# 地理标志产品基础库（gi_products.json）

- 记录数：4,400 个地理标志产品
- 覆盖：31 个省级行政区、352 个地级市
- 字段：product_name（产品名称）、province（省份）、city（城市）、districts（区县列表）、sensory_characteristics（感官特征）
- 时间跨度：2005 年至 2023 年批准公告

## 数据来源

数据来自公开仓库 `JinQiangShi/Chinese-Nationnal-Geographic-Products`，该仓库从国家知识产权局地理标志产品检索网站（https://ggfw.cnipa.gov.cn/dlbzsq/dbQuery）下载并解析 2005–2023 年的地理标志保护产品批准公告：

- 原质监总局地理标志保护产品批准公告（2005–2018）
- 国家知识产权局地理标志保护产品批准公告（2019 至今）

仓库许可：MIT License。

## 使用边界

- 本文件是“产品基础库”，用于按产品名、产地、感官特征做检索和比对；
- 它不等于“本批次证据”，也不能证明某个批次的产品真实产自该地；
- 对外发布仍需核对公告原文、保护范围、专用标志授权和本批材料。
